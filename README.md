# TCKR — Desktop Stock & Crypto Ticker for Windows

**Website:** [tckr.pro](https://tckr.pro)  
**Microsoft Store:** [Get TCKR](https://apps.microsoft.com/detail/9N2JNHPL52V4)

TCKR is a stock ticker app for Windows 11 and Windows 10. It docks a scrolling, LED-style strip to the top of your desktop so stocks, ETFs, indices, and crypto stay in view while you work — without covering your apps.

This repository hosts **public release packages** (Windows MSIX sideload builds, and Mac disk images in the future). Source code lives elsewhere and is not published here.

---

## Why TCKR

Most ways of watching the market disappear the moment you switch windows. A browser tab only helps while it is in front. Windows Widgets can show a watchlist, but the full list is usually a click away.

TCKR is built for the desk you already use:

- **Always visible** — docks like the taskbar, so maximized apps sit below it
- **One strip for everything** — stocks, ETFs, indices, and crypto together
- **Smooth and readable** — 60 FPS scrolling with color-coded day changes
- **Your layout** — pick the monitor, height, scroll speed, and transparency
- **No API key required** — works out of the box; an optional free Finnhub key unlocks Finnhub stock quotes and real-time streaming with PRO

Free to install. **TCKR PRO** is a **$14.99 one-time** upgrade — no subscription.

---

## Features in free TCKR

- Docked ticker on Windows 10 and 11
- Up to **5 symbols** (stocks, indices, and crypto share the limit)
- Stocks, indices, and crypto with **no API key** (Yahoo Finance; quotes can be delayed)
- Optional free Finnhub key for Finnhub stock quotes
- Price updates on a polling timer (**60 seconds** minimum)
- 60 FPS LED-style scroll
- Choose any monitor
- Adjustable height, speed, and transparency
- Market-aware update timing
- Settings stored locally on your PC

## TCKR PRO

Unlock the full desktop ticker with a one-time Microsoft Store purchase:

| PRO unlock | What you get |
|---|---|
| **More symbols** | Higher limits based on your Finnhub plan (up to 50 on a free Finnhub key, 250 on Basic, and higher plans remove TCKR’s stock-symbol cap) |
| **Real-time prices** | WebSocket streaming for stocks during market hours when a Finnhub key is set |
| **Dual ticker** | A second row for more symbols **or** live finance headlines |
| **Finance news** | Headlines from Reuters, CNBC, Yahoo Finance, MarketWatch, and Seeking Alpha |
| **Price Watch** | Alerts when a symbol crosses your target |
| **Charts at a glance** | Historical mini-sparklines and hover charts (1D / 5D / 1M) |
| **LED look** | Bloom, scan matrix, glass cover with glare, and text glow |
| **Multi-monitor span** | One continuous ticker across several displays |
| **Faster polling** | 10-second minimum update interval when not streaming |

PRO never expires. Free features never expire either.
